1. Overview & Core Principle

Internet Speed Meter & Ping does NOT collect, transmit, store, or sell any personally identifiable information (PII). All speed and latency calculations occur exclusively on your local device in real time.

This Privacy Policy explains how our application operates, which device permissions are requested, and why they are necessary to provide network monitoring functionality.

2. Information Handled by the App

A. Network Traffic & Data Counters

The App reads standard operating system network statistics provided by Android (via android.net.TrafficStats and NetworkStatsManager). This measures the total bytes transferred across Wi-Fi and Cellular interfaces.

  • No content inspection: We do not inspect packet contents, user requests, URLs, browsing history, or personal communications.
  • Local storage only: Daily and monthly data counters are saved purely inside the App's private local database on your device. Nothing is uploaded to any server.

B. Latency & Ping Measurements

To display real-time latency (ping) in the status bar and shade, the App sends standard lightweight ICMP/socket echo requests to well-known public DNS resolvers (such as Cloudflare 1.1.1.1 or Google DNS 8.8.8.8).

  • These echo requests contain no user identifiers, accounts, or personal data.
  • Only the round-trip response duration in milliseconds (ms) is recorded to display current network stability.

3. Device Permissions & Justification

The App requests only the strictly required permissions to deliver its utility features in accordance with Google Play Policy:

Permission System Name Exact Purpose
Notifications POST_NOTIFICATIONS Required on Android 13+ to display the real-time speed and ping meter in your status bar and notification drawer.
Foreground Service FOREGROUND_SERVICE & FOREGROUND_SERVICE_DATA_SYNC Maintains persistent, low-power background execution so the speed monitor stays accurate while you browse or use other apps.
Network State ACCESS_NETWORK_STATE Detects whether you are connected to Wi-Fi, Mobile Data, or Offline, allowing accurate split data statistics.
Wi-Fi State ACCESS_WIFI_STATE Measures Wi-Fi signal level to display connection quality indicators.
Internet INTERNET Strictly used to send lightweight ping packets to public DNS servers and run user-initiated diagnostic latency checks.
Run at Startup RECEIVE_BOOT_COMPLETED Automatically restarts the speed indicator after device reboot if you enable "Start on Boot" in settings.
Display Over Apps SYSTEM_ALERT_WINDOW (Optional) Used only if you manually enable the floating speed bubble / overlay widget.
